## Basic Details

### Team Name: JERIN PAPPA

### Team Members

### Project Description

**NULLEX** is a completely unnecessary interactive web experience designed to waste the user's time in the most entertaining way possible.

Users must navigate a rabbit through a maze, survive an intentionally pointless registration and login process, help a monkey collect coconuts, cross a dangerous road, and finally smash a coconut 25 times — only to discover that the entire journey was for **one coconut**. 🥥

### The Problem (that doesn't exist)

People spend far too much time doing useful things.

There was clearly a serious problem in society:

> **Not enough websites were wasting people's time for absolutely no reason.**

NULLEX was created to solve this completely imaginary crisis.

### The Solution (that nobody asked for)

We created an unnecessarily complicated journey for obtaining a coconut.

The user must:

1. Guide a rabbit through a maze.
2. Survive an absurd registration process.
3. Enter a completely pointless login.
4. Help a monkey collect coconuts.
5. Cross a road while avoiding cars.
6. Smash a giant coconut **25 times**.
7. Click **LETS GO →**.
8. Watch a monkey deliver another coconut.
9. Wait for the coconut to dramatically zoom toward the screen.
10. Finally discover the truth:

**YOU ENTERED THIS SITE FOR A COCONUT.**

The entire experience tracks how much time the user successfully wasted.

# Key Features

### 🐇 Rabbit Maze

The user has to manually guide a rabbit through a maze.

Touching the maze boundary resets the attempt.

The objective is simple:

**GET THE RABBIT HOME.**

There is absolutely no reason for this.

### 🌸 Unnecessary Registration

The registration page makes entering a password unnecessarily difficult.

Each password character requires confirmation.

The CAPTCHA also intentionally uses confusing colour rules.

### 🔐 Fake Login

The login system pretends to verify the user's credentials.

The login button attempts to escape the user several times before finally allowing the click.

Even after entering credentials, NULLEX claims:

**NO SUCH ACCOUNT FOUND.**

Then immediately admits:

**HAHA. WE TRICKED YOU!**

### 🐒 Coconut Adventure

The user enters a ridiculous adventure involving a monkey and coconuts.

### 🚗 Traffic Challenge

The monkey must cross a road while avoiding moving vehicles.

The player can use:

* Arrow Keys
* W
* A
* S
* D

### 🥥 Coconut Destruction

The user must click a giant coconut **25 times**.

Why 25?

There is no reason.

### 🎬 Final Cinematic

After completing the coconut challenge, the user can click:

**LETS GO →**

A monkey enters the scene, presents a coconut, and the coconut dramatically zooms toward the screen.

### ⏱️ Time Waster

NULLEX tracks the total amount of time spent on the journey.

The final screen proudly displays:

**SUCCESSFULLY WASTED THIS TIME**
